# Servego Platform

This repository contains the Servego platform frontend and backend.

## Structure

- `frontend/` - UI application
- `backend/` - API / server application
- `docs/` - project documentation

## Backend

See `backend/README.md` for the backend folder structure, environment variables, and run commands.

Common commands:

```bash
cd backend
npm i
npm run dev
```

## Getting Started

- Frontend: follow `frontend/README.md`
- Backend: follow `backend/README.md`
